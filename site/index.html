Install

  1. Pobierz paczkę na swój system i rozpakuj ją w dowolnym folderze.
  2. Linux: uruchom launcher/patina. Windows: uruchom launcher\patina.exe.
  3. Zaloguj się kontem Microsoft, utwórz instancję i graj. Kolejne wersje Patina zainstaluje sama.
  1. Download the package for your system and unpack it in any folder.
  2. Linux: run launcher/patina. Windows: run launcher\patina.exe.
  3. Sign in with a Microsoft account, create an instance and play. Patina installs later versions itself.

Pytania

Questions

Windows ostrzega przed nieznanym wydawcą

Patina nie jest jeszcze podpisana certyfikatem, więc SmartScreen może pokazać ostrzeżenie. Kliknij „Więcej informacji” i „Uruchom mimo to”. Kod jest w całości na GitHubie.

Czy potrzebuję konta Minecraft?

Tak. Patina gra tylko na oryginalnym koncie Minecraft: Java Edition i nie zawiera plików gry.

Czym różni się klient Rust od Fabric?

Klient Rust to osobny program napisany od zera (na bazie Horizon) — bardzo szybki, ale mody z Fabric w nim nie działają. Wersja Fabric to zwykły Minecraft z modem Patina, więc działa z innymi modami.

Windows warns about an unknown publisher

Patina is not code-signed yet, so SmartScreen may show a warning. Click "More info" and "Run anyway". All of the code is on GitHub.

Do I need a Minecraft account?

Yes. Patina only plays with a genuine Minecraft: Java Edition account and ships no game files.

How is the Rust client different from Fabric?

The Rust client is a separate program (based on Horizon) — very fast, but Fabric mods do not run in it. The Fabric version is regular Minecraft with the Patina mod, so it works with other mods.
